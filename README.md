# Word-ZIP-DOCX-HTML-Excel

Minimal DOCX (Word ZIP format) converter to:
- HTML
- Excel (.xlsx)

## Usage

```bash
python docx_to_html_excel.py /path/to/input.docx
```

Optional output paths:

```bash
python docx_to_html_excel.py /path/to/input.docx --html-out /path/to/output.html --excel-out /path/to/output.xlsx
```
